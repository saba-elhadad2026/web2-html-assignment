# واجب إنشاء صفحة HTML - مادة ويب 2

## وصف المشروع
هذا المستودع يحتوي على تطبيق عملي لإنشاء صفحة ويب متكاملة ومنظمة باستخدام لغة **HTML5** وتنسيقها باستخدام **CSS3**.

## محتويات المستودع
- **`index.html`**: الصفحة الرئيسية للموقع، وتحتوي على:
  1. **رأس الصفحة (`<header>`)**: يضم عنوان الصفحة وقائمة تنقل (`<nav>`) للانتقال السريع بين الأقسام.
  2. **المحتوى الرئيسي (`<main>`)**: مقسم إلى ثلاثة أقسام منظمة داخل بطاقات:
     - قسم **نبذة عني** للتعريف بالتخصص.
     - قسم **جدول المواد والمهارات** لعرض البيانات بشكل منظم باستخدام الوسم `<table>`.
     - قسم **نموذج التواصل** باستخدام الوسم `<form>` وحقول الإدخال المختلفة.
  3. **تذييل الصفحة (`<footer>`)**: يحتوي على حقوق النشر.
- **`README.md`**: ملف توثيقي يشرح بنية الكود وأقسام الصفحة.

## ملاحظات تقنية
- تم الالتزام بكتابة تعليقات (`<!-- Comment -->`) توضيحية قبل وبعد كل جزئية في الكود لتسهيل القراءة والصيانة.
- تم ضبط اتجاه الصفحة ليدعم اللغة العربية بالكامل (`dir="rtl"`).
